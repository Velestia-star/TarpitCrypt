# TarpitCrypt 整活路线图

> 目标：让逆向方 / AI agent 在「判断自己是否拿到了真数据」这件事上反复付出代价。
> 不承诺数学上不可破：Argon2 的成本有硬件上限，真正能放大的，是**不确定性和验证成本**。

## 一句话定位

| 层 | 是什么 | 用户要记的秘密 |
| --- | --- | --- |
| `tarpitcrypt.py` | 单口令基础加密：Argon2id + AEAD | 一个口令 |
| `armor/` | 整活层：多层不可区分容器 + 伴生诱饵 | 一个主口令 |

默认体验是**一个口令**。keyfile、诱饵口令、PoW、层数都在「高级」里；不打开就全部不设。

## 现状盘点

- v1 的诱饵层是**可见的**（`FLAGS.bit2` + `DECOY_LEN` 明文），命中还会返回
  `is_decoy`、退出码 2。它给的是「一个备用口令」，可否认性为零，不是反 AI 主力。
- armor v3 才是反 AI 部分：层数、真/诱饵/死层分布、口令、伴生包每次随机；
  所有层尺寸对齐；默认 4 层 + 伴生诱饵 + 均衡投毒。
- 已有度量：`probe_agent.py`（模拟三组 agent）、`content_probe.py`（真实 LLM
  吞指令）、`container_benchmark.py`（轮数 + API usage token）。

## 设计原则

1. **只留一个必须记住的秘密**：主口令。其他口令由容器随机生成，写进假线索或直接丢弃。
2. **不靠源码保密**：项目开源，所以不确定性必须来自「每次生成都不同」。
3. **不给确定性判据**：不解开即真、不报层号、不返回真伪标记。
4. **指标是确定性，不是轮数**：关键看「知情 agent 能否确定性定位真层」。
5. **只做信息误导**：不执行、不联网、不碰第三方系统、不指向真实主机。

## 路线

### P0 单口令默认体验（本轮）

- 在线版 / 本地网页版主表单只留 口令 / 确认 / 强度；keyfile、PoW、诱饵层收进「高级」。
- CLI 帮助与 README 明确：`encrypt file out.tarpit` 只问口令，`--keyfile` /
  `--decoy` 是可选兼容项。
- 不改变 v1 文件格式；旧文件照常解。

### P1 把 armor 变成主入口

- README / 首页 / 在线版入口统一引导「想整活 → armor」，v1 只作为基础加密。
- 默认 4 层 + 伴生诱饵 + 均衡投毒已经是合理默认；补一个「一键整活」说明。
- 保留「还原不报层号 / 真伪」这条硬约束。

### P2 容器层加码（候选，按度量取舍）

- 假 `.tarpit` 样本：头部 / 尺寸合法、口令只写在假线索里，且不指向真实主机。
- 嵌套容器：某层还原后是另一个 `.armored`，增加递归分支（需先评估还原体验与体积）。
- 口令池分层：部分线索只对诱饵层有效、部分完全无效，避免「线索全试一遍」被穷举。
- 继续做结构同分布：不让「层大小 / 有没有填充 / 有没有某目录」成为剪枝信号。

每加一项，先跑 `probe_agent.py` / `container_benchmark.py`，看「确定性定位真层」是否
下降；不为了复杂度而复杂度，也不为了效果牺牲还原保真度。

### P3 内容层加码

- 现有七种投毒侧重保留；`AGENTS.md` / `CLAUDE.md` / `MEMORY.md` 这类 agent
  指令文件已有。
- 候选：假 SBOM、假 CI 安全门、假 IR 结论、RAG 知识库文章、假威胁情报。
- 红线不变：纯文本、不可执行、不联网、不写真实主机 / 域名 / IP。

### P4 度量与回归

- `probe_agent.py`：基线 / 盲 / 读源码三组，主指标「能否确定性定位真层」。
- `content_probe.py --real`：真实 LLM 吞指令比例；规则模拟只做结构自检。
- `container_benchmark.py`：轮数与 token 取 API usage，不估算。
- CI 保留非阻断冒烟；关键指标变了在 PR 里贴前后对照。

## 不做什么

- 不把 `mem/time/rounds` 调到「合法用户也解不动」——那是在惩罚自己。
- 不声称「无限成本」「不可破解」；Argon2 只是把每次猜测变贵。
- 不做免杀、反调试、执行型 payload、供应链投毒。
- 不破坏 v1 / v3 旧格式兼容；要升格式必须带迁移脚本和旧样本回归。

## 下一步

P1（把 armor 做成主入口）成本最低、收益最直接；P2 里的「假 `.tarpit` 样本」
和「嵌套容器」最值得先做效果对照。P3 的内容层可以并行，但要先定度量口径。
