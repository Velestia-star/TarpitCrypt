TarpitCrypt

把程序包加密成「双击即可运行」的单文件 exe。明文不长期留盘。

本仓库已精简为纯本地工具，在线加密版已移除。本页仅作项目说明。

使用

pip install argon2-cffi cryptography pyinstaller
python armor/build_runner.py      # 构建一次通用启动器
python armor/armor_gui.py         # 打开单页 GUI

GUI：拖入程序包 → 填两次口令 → 选启动器 → 生成加密 exe。 分发只需这一个 exe；对方双击输口令即可运行原程序。

命令行

python armor/runtime_pack.py build MyApp -o MyApp_protected.exe \
  --password '你的口令' --runner armor/dist/RTPK_Runner.exe

能力边界

静态读分发包拿不到原文件；无口令无法解密；退出后覆写擦除临时目录。 运行时明文必进内存，无法阻止调试器 dump。不做免杀、注入、反沙箱。

仅用于加固你自己拥有或已获授权的程序包。
