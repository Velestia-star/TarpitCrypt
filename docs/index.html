            文件存在哪里？
            
    
            这个页面是纯前端的，浏览器不允许网页读取或打开你的本地文件夹——
      也正是这条限制，保证了你的文件不会离开浏览器。
            
    
            你加密好的 .tarpit 和原来的文件，都在浏览器的下载目录里：
            
    
              
      
            • Windows 默认：C:\Users\你的用户名\Downloads
              • 
      
            • Edge / Chrome：设置 → 下载 → 可查看和修改「位置」
              • 
      
            • 想每次自己选目录：打开「下载前询问每个文件的保存位置」
              • 
    
            
    
            想让按钮真的打开文件夹，用仓库里的命令行版或本地网页版——它们有文件系统权限。
