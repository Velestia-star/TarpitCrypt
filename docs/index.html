TarpitCrypt

正常双击即用；只有 AI / 自动化逆向时才会踩进成本陷阱。

分发出去的是一个普通单文件 exe：双击直接运行，不弹口令。假包、诱饵源码、 伪造索引和反调试降级会把 AI 分析、动态提取与云端爆破的时间、token、算力成本放大。

快速开始

pip install argon2-cffi cryptography pyinstaller
python build_runner.py      # 构建一次通用启动器
python armor_gui.py         # 打开单页 GUI

GUI：拖入程序包或整个文件夹 → 自动识别/选择入口 → 设置假包与诱饵 → 生成。

命令行

python runtime_pack.py build MyApp -o MyApp_protected.exe \
  --runner dist/RTPK_Runner.exe --decoys 12 --farm-mb 8

文件夹入口可用 --entry 指定；默认排除 .git、缓存、日志和 .env，保留 node_modules 等运行时依赖。

四条陷阱链路

陷阱作用
假包 + 昂贵 KDF每个假包都宣称高成本 Argon2id，真实密钥随机
诱饵源码农场大量逼真假工程与嵌套假包，消耗静态分析 token
伪造索引多处假 footer，误导自动扫描与提取
反调试 / 反 AI 降级调试器或 Agent 环境触发慢速迷宫与诱饵投放

能力边界

没有口令意味着密钥在本地，具备完整读码能力的人最终仍能还原。本工具抬高的是 AI 与自动化工具的成本，不承诺不可破解；不联网、不破坏主机、不注入第三方进程。

仅用于加固你自己拥有或已获授权的程序包。
